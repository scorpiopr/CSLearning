1. c++和Java的区别

以下是 C++ 与 Java 核心区别的 Markdown 对比表格：

对比维度	C++	Java
执行与跨平台机制	直接编译为机器码，执行效率极高；仅支持源码级跨平台，不同操作系统需重新编译。	先编译为字节码，依赖各平台的 JVM（Java虚拟机）运行；支持二进制级“一次编写，到处运行”。
内存管理方式	手动管理为主（new/delete），现代 C++ 辅以智能指针，控制精确但存在内存泄漏与野指针风险。	自动垃圾回收（GC），由 JVM 自动分配与回收内存，安全性高，但会带来短暂的停顿（STW）。
指针与底层操作	支持原生指针，可直接进行内存地址运算和硬件寄存器操作，对底层控制力极强。	屏蔽显式指针，仅保留安全的对象引用（Reference），无法直接操作物理内存。
编程范式与继承	多范式语言（支持面向过程、面向对象、泛型）；类支持多重继承。	纯面向对象语言（除基本类型外）；类仅支持单继承，通过实现多个接口（Interface）达成多态。
性能与资源开销	无虚拟机开销，冷启动极快，内存占用精确可控，适合对延迟极度敏感的场景。	启动较慢且基础内存占用高（需加载 JVM），但经过 JIT 即时编译预热后长期吞吐量极高。
泛型与多态实现	模板（Template）在编译期展开，实现零运行时开销的静态多态，但会增大编译产物体积。	泛型（Generics）采用类型擦除机制，仅在编译期检查类型，运行时统一视为 Object。
开发效率与安全性	语法复杂，无默认数组越界检查，一旦发生非法内存访问通常直接导致进程崩溃。	语法规范统一，标准库与开源生态庞大，自带边界检查与完善的异常处理机制，迭代效率高。
主流应用场景	操作系统、驱动开发、游戏引擎、高频量化交易、数据库内核、音视频与嵌入式开发。	企业级后端微服务、大型电商与金融核心系统、Android 应用开发、大数据处理组件。
